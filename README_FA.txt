چله‌یار مهدوی – پروژه بومی اندروید با Kotlin
============================================

نام برنامه: چله‌یار مهدوی
شناسه: ir.chillehyar.mahdi
نسخه: 1.2-kotlin (versionCode 42)
حداقل اندروید: 6.0 (API 23)
Compile SDK: 36

امکانات موجود در این نسخه
-------------------------
- صفحه خانه و نمایش پیشرفت چلهٔ ۴۰ روزه
- ثبت دستی ۴۰ روز چله و ذخیرهٔ نیت و تاریخ شروع
- پنج عادت پیش‌فرض، هرکدام با صفحهٔ اختصاصی
- جدول اختصاصی هر عادت: ۱۰ ریزکار × ۴۰ روز (۴۰۰ خانه)
- تغییر وضعیت هر خانه با لمس: خالی، ✅ لقمه کوچک، 🚫 لقمه ویژه، ❌ لقمه اضطراری
- امکان ویرایش نام ۱۰ ریزکار برای هر عادت
- شمارش و درصد پیشرفت هر عادت و گزارش کلی
- ثبت روزانه و محاسبهٔ نفس
- یادداشت‌ها و تاکتیک‌های مقابله با وسوسه (بدون فیلد شرح/علت شکست)
- یادآور روزانه با اعلان اندروید و تلاش برای بازیابی زمان‌بندی پس از راه‌اندازی مجدد
- انتخاب و پخش فایل صوتی محلی
- پشتیبان‌گیری و بازیابی اطلاعات در قالب JSON از طریق اشتراک‌گذاری متن
- ذخیره‌سازی محلی با SharedPreferences؛ بدون نیاز به اینترنت برای استفادهٔ عادی

نکته‌های مهم
------------
- این پروژه یک نسخهٔ اولیهٔ قابل توسعه است؛ پیش از انتشار عمومی باید روی چند دستگاه واقعی آزمایش شود.
- زمان‌بندی دقیق اعلان در اندرویدهای جدید ممکن است به مجوز «Alarms & reminders» وابسته باشد. اگر مجوز دقیق موجود نباشد، زمان‌بندی جایگزین اندروید استفاده می‌شود.
- فایل صوتی انتخاب‌شده در این نسخه برای پخش دستی است و هنوز به‌عنوان صدای کانال اعلان تنظیم نشده است.
- عادت شخصی در این نسخه به‌صورت نام ذخیره می‌شود؛ جدول ۴۰۰ خانهٔ اختصاصی فعلاً برای پنج عادت پیش‌فرض فعال است.
- پشتیبان‌گیری فعلی JSON متنی است، نه فایل ZIP مستقل.

ساخت APK با GitHub Actions
--------------------------
1. تمام محتویات این پوشه را در ریشهٔ مخزن GitHub قرار دهید.
2. به زبانهٔ Actions بروید.
3. گردش‌کار Build Android APK را اجرا کنید (یا یک commit روی شاخهٔ main/master انجام دهید).
4. پس از موفقیت، از بخش Artifacts فایل Chillehyar-debug-apk را دریافت کنید.

این مخزن عمداً APK آماده و آزمایش‌نشده را به‌عنوان نسخهٔ نهایی معرفی نمی‌کند؛ موفقیت ساخت در Actions و نصب و آزمایش روی گوشی باید جداگانه تأیید شود.

روش انتقال ZIP به مخزن با گوشی
------------------------------
1. ZIP را در ریشهٔ مخزن GitHub آپلود کنید؛ فعلاً Workflow به‌صورت خودکار با آپلود ZIP اجرا نمی‌شود.
2. مخزن را در Codespaces باز کنید.
3. در ترمینال Codespaces اجرا کنید (نام فایل را دقیقاً مطابق فایل آپلودشده بنویسید):
   unzip -o Chillehyar_Kotlin_GitReady_v1.2.zip -d .
4. پس از استخراج، مطمئن شوید فایل‌های settings.gradle، build.gradle و پوشهٔ app در ریشهٔ مخزن دیده می‌شوند.
5. ZIP را حذف کنید و تغییرات استخراج‌شده را commit و push کنید.
6. در GitHub > Actions، گردش‌کار Build Android APK را با گزینهٔ Run workflow اجرا کنید.
