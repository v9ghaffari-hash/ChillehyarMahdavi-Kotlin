چله‌یار مهدوی پیشرفته — نسخهٔ ۳۱ بومی Kotlin
================================================

این پروژه یک بازسازی بومی Android با Kotlin و Jetpack Compose است؛ رابط اصلی با WebView یا صفحهٔ HTML ساخته نشده است.

امکانات پیاده‌سازی‌شده در سورس این نسخه:
- داشبورد چلهٔ ۴۰روزه، تقویم روزها و چک‌لیست روزانه
- عادت‌های پیش‌فرض قرائت قرآن، خوش‌اخلاقی و دعا برای فرج، به‌علاوهٔ ساخت عادت شخصی
- جدول ۴۰۰ خانه برای هر عادت (۱۰ ردیف × ۴۰ خانه) با چهار وضعیت: خالی، لقمه کوچک، لقمه ویژه، لقمه اضطراری
- هدف سه‌سطحی عادت و هدف کوچک اختصاصی هر ردیف
- ویرایش نام و مشخصات عادت شخصی و حذف عادت شخصی
- یادداشت اختصاصی عادت، یادداشت روزانه و محاسبهٔ نفس
- جدول الف و فضیلت‌ها در ۱۱ دسته با ذخیرهٔ جداگانه بر اساس تاریخ
- چک‌لیست ۱۶ موردی افزایش انگیزه و نگهداری سابقهٔ روزانه
- فرم تحلیل علت لغزش، ذخیرهٔ راهکارها و حذف سوابق
- گزارش پیشرفت چله و شمارش انواع خانه‌های عادت
- یادآور روزانهٔ اندروید و یادآور اختصاصی هر عادت با متن دلخواه
- تنظیم مقیاس کلی نوشته‌ها و انتخاب رنگ اصلی Material
- خروجی‌گرفتن و بازیابی نسخهٔ پشتیبان JSON از طریق انتخاب‌گر فایل اندروید
- ذخیره‌سازی محلی با SharedPreferences

محدودیت‌ها و وضعیت آزمون:
- این ZIP سورس پروژه است، نه APK آماده.
- این پروژه در محیط فعلی با Android SDK/Gradle کامپایل نشده است؛ بنابراین قبل از انتشار، GitHub Actions باید با موفقیت اجرا شود و سپس APK روی دستگاه واقعی آزمایش شود.
- اعلان‌ها با AlarmManager و زمان‌بندی قابل‌تأخیر در حالت صرفه‌جویی انرژی اجرا می‌شوند؛ اندروید/سازندهٔ گوشی ممکن است اعلان را با تأخیر نمایش دهد. مجوز اعلان و تنظیمات باتری دستگاه را بررسی کنید.
- این نسخه بازسازی بومیِ بسیاری از امکانات اصلی نسخهٔ ۲۹ است، اما هنوز معادل صددرصدی تمام جزئیات نسخهٔ وب نیست: انتخاب فایل صوتی دلخواه برای صدای اعلان، تنظیمات جداگانهٔ چند فونت برای سربرگ/عنوان/متن/کادرها، و ویرایش مستقیم سوابق قدیمی چک‌لیست انگیزه و تحلیل لغزش هنوز کامل منتقل نشده‌اند. ظاهر و رفتار بعضی بخش‌ها نیز باید پس از نصب با نسخهٔ مرجع مقایسه شود.

ساخت با GitHub Actions:
1. محتویات پروژه را در ریشهٔ مخزن GitHub قرار دهید.
2. از تب Actions، گردش کار Build Chillehyar Native V31 را اجرا کنید.
3. پس از سبزشدن اجرا، artifact با نام Chillehyar-V31-native-debug-apk را دریافت کنید.
4. APK را روی گوشی نصب و تمام صفحات، یادآورها و پشتیبان‌گیری را آزمایش کنید.
